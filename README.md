# Hookup

Hookup is a premium, privacy-first dating platform built around a Chooser vs. Be Chosen model. The experience blends identity verification, secure messaging, and a modern UI.

## Stack

- Frontend: React 19, TypeScript, Vite, Tailwind, Framer Motion, React Router

## Run locally

```bash
cd frontend
npm install
npm run dev
```

## Notes

- The current implementation includes the premium UI experience, core pages, and mock data.
